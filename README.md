# BCI – מדריך תחזוקה קצר

האפליקציה: https://ozzvik.github.io/bci
כל שינוי בקובץ כאן עולה לאוויר תוך כדקה (רענן את האפליקציה בטלפון).

---

## 1. דברים שמשנים מתוך האפליקציה (בלי קוד)

| מה | איפה |
|---|---|
| סטוקים ותוכניות דישון | דף **דישון** ← לשוניות "סטוקים" / "תוכניות" |
| שם ותאריך תחילת פריחה | דף **אצווה** ← "✏️ שם ותאריך האצווה" |
| הערות, משימות, דישון מותאם לשלב | דף **אצווה** |
| משימות ומלאי (מסונכרן עם CannaFlow) | דף **ניהול** |
| קישורים לאפליקציות אחרות | דף הבית ← ⚙️ |
| חיבור אצווה בגאנט לחדר הפריחה | **ניהול** ← "חדרים ואצוות" ← 🔗 |

## 2. איך עורכים קובץ ב-GitHub

1. פתח את https://github.com/ozzvik/bci ולחץ על שם הקובץ.
2. לחץ על העיפרון ✏️ (**Edit this file**).
3. לחץ **Ctrl+F** (במק: **Cmd+F**) וחפש את מה שצריך (ראה טבלה למטה).
4. שנה – רק את הערך. לא לגעת בפסיקים, מרכאות וסוגריים.
5. לחץ על הכפתור הירוק **Commit changes...** ← ושוב **Commit changes**.
6. חכה דקה ורענן את האפליקציה.

### אם משהו נשבר
בתוך הקובץ ב-GitHub ← **History** ← פתח את הגרסה הקודמת ← העתק את כל התוכן (כפתור **Copy raw file**) ← ערוך את הקובץ הנוכחי ← סמן הכול והדבק ← Commit.

## 3. מה נמצא איפה

| רוצה לשנות | קובץ | לחפש |
|---|---|---|
| יעדי VPD / טמפ׳ / לחות / ייבוש, שמות השלבים, שבועות | `app.js` | `const RECIPE` |
| צבעים (כהה – בתחילת הקובץ, בהיר – אחרי `prefers-color-scheme: light`) | `style.css` | `--bg` |
| נוסחת EC (סך היסודות ÷ 500 + 0.4 מים) | `fert.js` | `EC_DIV` |
| טקסטים וכותרות של דף | הקובץ של הדף | הטקסט עצמו |
| רשימת חומרי המלאי המובנית (חייבת להתאים ל-CannaFlow) | `cf.js` | `CF_MATS` |

### דוגמה – יעדי שלב (ב-`app.js`)
```
{ id: 'bulking', name: 'Bulking', en: 'Bulking', from: 4, to: 6, vpd: [1.1, 1.4], temp: [24, 27], rh: [50, 60], db: [15, 20] },
```
- `from` / `to` – שבועות הפריחה של השלב
- `vpd`, `temp`, `rh`, `db` – [מינימום, מקסימום] של VPD, טמפרטורה, לחות ואחוז ייבוש
- `id` – אל תשנה (מקשר לתוכנית הדישון באותו שם)

## 4. הקבצים

| קובץ | מה זה |
|---|---|
| `index.html` | דף הבית |
| `batch.html` | האצווה: שלבים, גרף, דישון לשלב, הערות, משימות, חיבור לגאנט |
| `grow.html` / `photos.html` | גרפים מפורטים / תמונות מהמצלמות |
| `prop.html` | ריבוי |
| `fert.html` + `fert.js` | מחשבון הדישון |
| `mgmt.html` + `cf.js` | ניהול – משימות, חדרים, מלאי (CannaFlow) |
| `app.js` | חלקים משותפים לכל הדפים (יעדים, גרפים, מקלדת מספרים) |
| `style.css` | עיצוב |
| `sw.js` | שומר את האפליקציה בטלפון |

### לא לשנות בלי לדעת מה עושים
- `cf.js` – הסנכרון עם CannaFlow (טעות כאן יכולה לפגוע בנתוני הגאנט)
- `sw.js`
- קוד השרת (`TrayApp_server.js` ב-Google Drive) – שינוי דורש גם פריסה מחדש ב-Apps Script
